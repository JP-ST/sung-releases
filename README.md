# Sung – Diktieren für macOS

fn-Taste halten, sprechen, loslassen: Der Text steht im Fenster, in dem du gerade schreibst.
Die Spracherkennung läuft auf deinem Mac, es geht nichts ins Internet.

## Herunterladen

**[Sung für macOS herunterladen](https://github.com/JP-ST/sung-releases/releases/latest)** –
dort unter „Assets“ die Datei `Sung-….dmg` anklicken.

Läuft auf Macs mit Apple-Chip und mit Intel-Prozessor.

## Installieren

1. Die heruntergeladene `.dmg`-Datei doppelt anklicken.
2. **Sung** auf den Ordner **Programme** ziehen.
3. Sung im Ordner Programme doppelt anklicken.

Beim ersten Öffnen meldet macOS, dass es Sung nicht überprüfen kann. Das ist bei Apps
außerhalb des App Stores normal. Einmalig freigeben:

4. **Systemeinstellungen** öffnen → **Datenschutz & Sicherheit** → ganz nach unten
   scrollen → bei „Sung wurde blockiert“ auf **Trotzdem öffnen** klicken und bestätigen.

## Beim ersten Start

Sung fragt nach zwei Freigaben, beide sind nötig:

- **Mikrofon** – damit Sung dich hört.
- **Bedienungshilfen** – damit Sung die fn-Taste bemerkt und den Text einfügen kann.
  In der Liste den Schalter bei Sung einschalten.

Danach lädt Sung einmalig das Sprachmodell (etwa 550 MB). Das dauert je nach Internet
ein paar Minuten.

## Benutzen

- **fn halten** und sprechen, **loslassen** – der Text erscheint.
- **fn + Leertaste** – freihändig, für längere Texte. Mit fn beenden.
- **Esc** – Aufnahme abbrechen.

## Updates

Sung schaut beim Start selbst nach einer neuen Version. Ist eine da, steht auf der
Startseite „Jetzt aktualisieren“. Ein Klick, Sung startet neu, fertig.
